# plugins/wrappit/.mcp.json

## What it is
The list of MCP servers the plugin adds. It has one: 'wrappit', a remote HTTP server at https://mcp.wrappit.dev/mcp.

## How to navigate it
One object under `mcpServers`. The key `wrappit` is the server name that Claude Code shows.

## What it interacts with
Claude Code reads it when the plugin is enabled. The server is run by the Wrappit service, not by this repo.

## Why it exists
So Claude can use the Wrappit connector in a session without the person setting it up by hand.

## Helpful notes
This is an HTTP server, so nothing is installed on the computer for it. If the server address changes, change it here and in the README.
